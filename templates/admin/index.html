Simple daily workflow

For the person managing the website

  1. Check new requests. Start with counseling requests, enquiries and payments marked as new or pending.
  2. Open one record. Read the person's details, update the status and add an internal note when needed.
  3. Publish content carefully. Write both English and Nepali versions, preview the page and publish only verified information.
  4. Use audit tools only when necessary. Do not change membership numbers or merge possible duplicates without checking the original records.
