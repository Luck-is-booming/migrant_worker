# MRN Ilam — Safe Foreign Employment Support Portal

A public-service web platform built for **Migrant Resource Network Ilam** to support safe, informed, and dignified foreign employment in Ilam, Nepal.

The website provides verified member records, membership application flow, notices, resources, safety guidance, and contact/support features for migrant workers, returnees, families, and community members.

## Live Website

🌐 [mrnilam.org.np](https://mrnilam.org.np)

## Overview

MRN Ilam helps users access reliable information related to safe foreign employment. The platform is designed to make organizational information easier to access, improve transparency through verified member records, and support users through resources, notices, and contact forms.

## Key Features

* Public homepage with organization overview and chairperson message
* Verified member directory with searchable member records
* Membership application form
* Manual QR/payment verification flow
* Notices and community updates
* Safe migration resources and document checklist
* Contact/support form
* Multi-language support for English and Nepali
* Responsive design for mobile and desktop users
* Admin-managed content and member records

## Tech Stack

* **Backend:** Django, Python
* **Frontend:** HTML, Tailwind CSS, JavaScript
* **Database:** PostgreSQL / SQLite
* **Media Storage:** Cloudinary
* **Deployment:** Render
* **Static Files:** WhiteNoise
* **Template Engine:** Django Templates
