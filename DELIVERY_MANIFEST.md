# MRN Ilam final delivery manifest

Delivery date: 2026-08-02

This package is a clean, client-ready Django source delivery. It contains no Git directory, `.env`, database, virtual environment, uploaded media, import reports, backups, or real credentials.

## Included

- Complete Django source, plain-language public templates, first-party responsive CSS/JavaScript, and migrations
- Complete English/Nepali public-copy translation source and compiled catalogue
- Safe member import/export commands and supplied source workbooks/DOCX
- Permanent membership-number sequence and issue ledger
- Counseling/contact workflows
- Administrator-managed membership fees/QR and private payment-proof workflow
- Authenticated private Cloudinary storage for new counseling/payment files
- Least-privilege staff groups and a task-focused operations dashboard
- Hidden legacy models and superuser-only read-only audit tools
- Chairperson photo preview in Admin and responsive display on the About page
- Clear news/notices/resources/programs/privacy/disclaimer/error pages
- Accessible desktop navigation and mobile drawer with responsive layouts from 320px upward
- One consistent approved organization seal across navigation, footer, favicons, manifest, metadata, and maintenance branding
- Render/Neon/Cloudinary/Resend configuration templates
- Tests, CI workflow, README, changelog and client/deployment documentation
- Static QA report at `docs/STATIC_QA_RESULTS.json`

## Not included by design

- Real secrets or service credentials
- Official payment QR or unverified membership fees
- Unverified registration/contact/leadership facts
- Production database or private submissions

Read `README.md`, `docs/FINAL_REFINEMENT.md`, `docs/EXTERNAL_CONFIGURATION_REQUIRED.md`, `docs/CLIENT_HANDOVER_OVERVIEW.md`, `docs/ADMIN_OPERATIONS_GUIDE.md`, and `docs/FINAL_TEST_REPORT.md` before deployment.
